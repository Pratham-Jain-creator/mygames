# Backup: procedural (code-drawn, landscape 224x126) Node cards

This is the look before the PNG-frame (assets/nodes) version. To go back:

1. Copy every file in `node_card/` back to `scenes/components/node_card/`, removing the `.bak` ending
   (e.g. `node_face.gd.bak` -> `node_face.gd`). Do the same for `node_card/variants/` ->
   `scenes/components/node_card/variants/`.
2. Copy `server_screen.gd.bak` -> `scenes/server/server_screen.gd`.
3. Delete nothing else; the new art files in `assets/nodes/` can stay.
4. Reopen the project in Godot.

Or just ask Claude: "revert the node cards to the procedural backup".
